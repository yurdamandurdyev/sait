# FORMA

Русскоязычное приложение для калорий, питания и тренировок. Чёрно-красная и бело-оранжевая темы, настоящие WebGL-сцены с объёмными мешами, 56 фотореалистичных изображений блюд и адаптивная вёрстка. Без внешних зависимостей и сетевых запросов.

## Открыть приложение

Скачайте **index.html** через Download raw file на GitHub и откройте двойным щелчком. Стили, код, рецепты, иллюстрации и 3D-движок встроены в этот файл. Интернет и сервер не нужны.

## Разработка

Требуется Node.js 20+. В существующей рабочей папке:

```sh
cd /workspace/sait
npm run build
npm test
npm start
```

Сервер слушает 0.0.0.0:3000. Порт можно изменить через PORT. После изменения исходников выполните `npm run build`: он обновит `bundle.js` и автономный `index.html`. Разметка редактируется в `index.template.html`.

## Персональное питание

В «Мой профиль» задаются тип питания, 3–5 приёмов пищи, время готовки, подготовка накануне, экономный/обычный/гибкий выбор, любимые и исключённые продукты, аллергены, безлактозные/растительные замены и акцент на белке. Базовая энергия зависит от возраста, пола, роста, веса, активности и цели; силовые цели и белковый акцент влияют на белковый ориентир. Активность уже включена в расчёт, тренировочные калории повторно не добавляются.

- База: 56 блюд с ингредиентами, шагами и приблизительным составом. Растительные и безлактозные версии пересчитывают состав и корзину.
- Обязательные ограничения фильтруются до подбора. Вкусы и бюджет влияют на предпочтение среди разрешённых блюд. Поддерживаются обычные названия «курица», «рыба», «мясо», «яйца», «сыр», «орехи» и точные названия/части названий ингредиентов.
- Порции подбираются отдельно для каждого блюда с целью приблизить фактические БЖУ к ориентирам и сохранить личную дневную калорийность. Это приближение, а не гарантия точного попадания в все макронутриенты. Фактические значения и отклонения видны в плане.
- При достаточном выборе блюда меняются во все семь дней. Если ограничения оставляют мало вариантов, повторения отмечаются явно. При отсутствии подходящей категории меню не заполняется запрещёнными блюдами.
- Замена затрагивает выбранное блюдо и порции дня, сохраняя остальные названия. Корзина суммирует все адаптированные ингредиенты семи дней и поддерживает отметки и скачивание.
- Стоимость — условная оценка по зафиксированным примерным рублёвым ценам ингредиентов; это не цены магазина, не региональная котировка и не гарантированный лимит бюджета. Покупки нужно округлить до реальных упаковок. Вес круп — сухой, бобовых — готовый, яиц — без скорлупы.
- При лечебных/специальных потребностях автоматическое меню приостанавливается; приложение не назначает лечебные диеты. Микронутриенты, взаимодействие с лекарствами и медицинские противопоказания не рассчитываются.

Аллергены определяются по составу рецепта. Безлактозные продукты сохраняют молочные аллергены. Следы аллергенов и производственное перекрёстное загрязнение автоматически не определяются — нужна проверка маркировки и конкретных продуктов.

## Фотореалистичные изображения

Для каждого из 56 базовых блюд сгенерировано отдельное изображение с естественным светом, керамикой и фактурой еды. Это сгенерированные примеры подачи, а не снимки приготовленных пользователем блюд. При адаптации рецепта фотография может не показывать замену ингредиента; состав персональной версии указан в рецепте.

`assets/food/sheet-0.webp` … `sheet-6.webp` содержат по восемь изображений (2 столбца × 4 строки). `photos.js` показывает каждую фотографию через отдельный SVG viewport без изменения исходного изображения. Фотографии соответствуют идентификаторам рецептов по порядку: 0–7, 8–15, … 48–55. Build встраивает все семь WebP-файлов в HTML; сервер, генератор изображений и Интернет для запуска не нужны. Размер автономного файла — около 4,1 МБ.

## 3D и оформление

`scene.js` — небольшой собственный WebGL-рендерер: торы, сферы, кубы и цилиндры, освещение, блики, вращение и параллакс. WebGL-сцены находятся на главной, в профиле, тренировках и корзине; в питании и рецептах используются фотографические композиции. Карточки и декоративные элементы используют дополнительные CSS-анимации. Переключатель тем и кнопка 3D-паузы находятся в шапке. Системная настройка уменьшения движения учитывается. За пределами экрана сцены не рендерятся; при паузе статический кадр сохраняется. Если WebGL недоступен, показывается CSS-композиция.

## Персональные тренировки

В «Мой профиль» задаются опыт, тренировочная цель, предпочтительный сплит, дни (2–6), бюджет времени, приоритет мышц, способность отжиматься, шаг веса и ограничения движений. В разделе тренировок оборудование выбирается отдельно для зала, дома и собственного веса.

- Автоматический сплит: всё тело через день, верх/низ при соседних днях и 4 занятиях, смешанный сплит на 5 дней, жим/тяга/ноги на 6. Можно выбрать предпочтительный сплит. Для нечётного числа дней чередование продолжается на следующей неделе.
- Календарь показывает группы мышц каждого дня и дни восстановления; карта тела различает основные и вспомогательные мышцы.
- 37 упражнений с анимированными SVG-схемами ключевых фаз, текстовыми подсказками и частыми ошибками. Это схемы, а не видео, не полноценная биомеханическая модель и не проверка техники пользователя камерой.
- Журнал сохраняет только отмеченные подходы: фактические повторы/секунды, вес, запас повторов (RIR) и оценку нагрузки. Есть таймер занятия, пауза, таймер отдыха, черновик, история и выгрузка JSON.
- Прогрессия веса предлагается после всех записанных подходов на верхней границе с запасом минимум 2 повтора. При тяжёлой нагрузке предлагается снижение, неполная запись не вызывает повышения. Для собственного веса прогрессия идёт в повторах/времени. Начальный рабочий вес не придумывается: его подбирает пользователь по контролю техники и запасу.
- Каждая четвёртая неделя программы уменьшает объём; программа отсчитывается от недели первого сохранённого занятия. Для незапущенного плана используется текущая неделя.
- График показывает фактические значения, а распределение подходов — записанную работу по основным группам мышц. Невыполненные подходы не включаются. Изменение профиля не удаляет историю.
- При острой боли, запросе допуска или боли в последней записанной тренировке автоматический силовой план приостанавливается. Возвращение после согласования нагрузки указывается в профиле; приложение не устанавливает диагноз и не назначает реабилитацию.

Расчёт плана — прозрачные правила для общего фитнеса, а не гарантированно оптимальное назначение тренера. Учитываются цель, опыт, возраст, фоновая активность, график, время, выбранные ограничения и фактические результаты. Оценка длительности приблизительная. Рост, вес и пол используются в расчёте питания; безопасный стартовый рабочий вес по ним не вычисляется. Произвольные заболевания, травмы и медицинские противопоказания автоматически не анализируются.

## Данные и ограничения

Данные сохраняются только в localStorage браузера: аккаунтов, синхронизации и серверной базы нет. Дневник еды относится к текущему дню недели. Обновление меню сбрасывает отметки еды и покупок, сохраняя воду и тренировку. Расчёт Миффлина — Сан Жеора предназначен для взрослых; формула не зависит от субъективного телосложения. Порции приближаются к калориям и БЖУ, но точное выполнение всех пищевых потребностей не гарантируется. Планы не определяют медицинскую совместимость нагрузки при заболеваниях, травмах или беременности. Удаление данных браузера удаляет сохранённый профиль.
