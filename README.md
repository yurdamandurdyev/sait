# FORMA

Приложение для плана питания, рецептов, списка покупок и тренировок. Интерфейс написан на React; расчёты и подбор плана находятся в отдельных JavaScript-модулях.

## Запуск

Требуется Node.js 20+.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный Vite. Для выпуска: `npm run build`; статические файлы появятся в `dist/`. Для просмотра сборки: `npm run preview`. Проверки расчётов: `npm test`.

## Структура

- `src/main.jsx` — React-экраны, навигация, формы и журнал тренировки.
- `src/react.css`, `style.css`, `design.css`, `refinement.css` — оформление и адаптивная сетка.
- `model.js` — питание, рецепты, расчёты и недельное меню.
- `training.js` — упражнения, программа и прогрессия нагрузок.
- `photos.js`, `assets/` — изображения блюд и тренировок.

Профиль, отметки еды, вода, покупки и история тренировок сохраняются в `localStorage` браузера. Старые данные пользователя читаются из тех же ключей.
