# FORMA

Русскоязычное приложение для калорий, питания и тренировок. Чёрно-красная и бело-оранжевая темы, настоящие WebGL-сцены с объёмными мешами, локальные иллюстрации и адаптивная вёрстка. Без внешних зависимостей и сетевых запросов.

## Открыть приложение

Скачайте **index.html** через Download raw file на GitHub и откройте двойным щелчком. Стили, код, рецепты, иллюстрации и 3D-движок встроены в этот файл. Интернет и сервер не нужны.

## Разработка

Требуется Node.js 20+. В существующей рабочей папке:

```sh
cd /workspace/sait
npm run build
npm test
npm start
```

Сервер слушает 0.0.0.0:3000. Порт можно изменить через PORT. После изменения исходников выполните `npm run build`: он обновит `bundle.js` и автономный `index.html`. Разметка редактируется в `index.template.html`.

## Питание

- 56 рецептов: 14 завтраков, 14 обедов, 14 ужинов и 14 перекусов.
- В стандартном недельном плане каждый приём пищи отличается во все семь дней, включая вегетарианский вариант с яйцами и молочными продуктами.
- Кнопка «Заменить» позволяет выбрать другое блюдо той же категории. «Новый вариант недели» меняет подборку. При ручной замене можно выбрать уже использованное блюдо.
- Порции всех блюд дня масштабируются по калориям. Замена пересчитывает порции и ингредиенты недельной корзины.
- Калории и БЖУ рецептов получены из приблизительного среднего состава ингредиентов, а не из лабораторного анализа или конкретных этикеток. Фактические БЖУ меню показаны отдельно от целевых.
- Каталог поддерживает поиск, фильтры и сортировку по времени или белку. В каталоге — базовые порции, в меню — персональные.
- Корзина содержит количество ингредиентов за семь дней; можно отмечать покупки и скачивать текстовый список. Вес круп — сухой, бобовых — готовый, яйца указаны по весу без скорлупы.

## 3D и оформление

`scene.js` — небольшой собственный WebGL-рендерер: торы, сферы, кубы и цилиндры, освещение, блики, вращение и параллакс. Сцены находятся на главной, в профиле, питании, рецептах, тренировках и корзине. Карточки и декоративные элементы используют дополнительные CSS-анимации. Переключатель тем и кнопка 3D-паузы находятся в шапке. Системная настройка уменьшения движения учитывается. За пределами экрана сцены не рендерятся; при паузе статический кадр сохраняется. Если WebGL недоступен, показывается CSS-композиция.

## Персональные тренировки

В «Мой профиль» задаются опыт, тренировочная цель, предпочтительный сплит, дни (2–6), бюджет времени, приоритет мышц, способность отжиматься, шаг веса и ограничения движений. В разделе тренировок оборудование выбирается отдельно для зала, дома и собственного веса.

- Автоматический сплит: всё тело через день, верх/низ при соседних днях и 4 занятиях, смешанный сплит на 5 дней, жим/тяга/ноги на 6. Можно выбрать предпочтительный сплит. Для нечётного числа дней чередование продолжается на следующей неделе.
- Календарь показывает группы мышц каждого дня и дни восстановления; карта тела различает основные и вспомогательные мышцы.
- 37 упражнений с анимированными SVG-схемами ключевых фаз, текстовыми подсказками и частыми ошибками. Это схемы, а не видео, не полноценная биомеханическая модель и не проверка техники пользователя камерой.
- Журнал сохраняет только отмеченные подходы: фактические повторы/секунды, вес, запас повторов (RIR) и оценку нагрузки. Есть таймер занятия, пауза, таймер отдыха, черновик, история и выгрузка JSON.
- Прогрессия веса предлагается после всех записанных подходов на верхней границе с запасом минимум 2 повтора. При тяжёлой нагрузке предлагается снижение, неполная запись не вызывает повышения. Для собственного веса прогрессия идёт в повторах/времени. Начальный рабочий вес не придумывается: его подбирает пользователь по контролю техники и запасу.
- Каждая четвёртая неделя программы уменьшает объём; программа отсчитывается от недели первого сохранённого занятия. Для незапущенного плана используется текущая неделя.
- График показывает фактические значения, а распределение подходов — записанную работу по основным группам мышц. Невыполненные подходы не включаются. Изменение профиля не удаляет историю.
- При острой боли, запросе допуска или боли в последней записанной тренировке автоматический силовой план приостанавливается. Возвращение после согласования нагрузки указывается в профиле; приложение не устанавливает диагноз и не назначает реабилитацию.

Расчёт плана — прозрачные правила для общего фитнеса, а не гарантированно оптимальное назначение тренера. Учитываются цель, опыт, возраст, фоновая активность, график, время, выбранные ограничения и фактические результаты. Оценка длительности приблизительная. Рост, вес и пол используются в расчёте питания; безопасный стартовый рабочий вес по ним не вычисляется. Произвольные заболевания, травмы и медицинские противопоказания автоматически не анализируются.

## Данные и ограничения

Данные сохраняются только в localStorage браузера: аккаунтов, синхронизации и серверной базы нет. Дневник еды относится к текущему дню недели. Обновление меню сбрасывает отметки еды и покупок, сохраняя воду и тренировку. Расчёт Миффлина — Сан Жеора предназначен для взрослых; формула не зависит от субъективного телосложения. Порции оптимизируются по общей энергии, а не по точному попаданию в каждый макронутриент. Планы не определяют медицинскую совместимость нагрузки при заболеваниях, травмах или беременности. Удаление данных браузера удаляет сохранённый профиль.
