# FORMA

Русскоязычное приложение для расчёта калорий, планирования питания и тренировок. Адаптивный интерфейс, локальные SVG-иллюстрации и объёмная CSS-анимация с поддержкой reduced motion. Внешние зависимости не нужны.

## Запуск

Требуется Node.js 20 или новее.

```sh
cd /workspace/sait
npm start
```

Сервер слушает порт 3000; изменить его можно переменной PORT. `npm test` проверяет расчёт калорий, изменение целей, соответствие порций норме, недельную корзину и вегетарианский вариант.

## Возможности

- Профиль: имя, возраст, пол, рост, вес, активность, телосложение, цель, опыт, питание.
- Расчёт по Миффлину — Сан Жеору, цели калорий, белков, жиров и углеводов.
- Меню на семь дней, порции под калорийность, рецепты с ингредиентами и шагами.
- Недельная корзина с отметками покупок и скачиванием списка.
- Тренировки в зале, дома и с собственным весом; таймер и отметка завершения.
- Дневные отметки еды, воды и тренировки; сохранение в localStorage.

## Границы первой версии

Это локальное приложение без сервера аккаунтов и синхронизации. База содержит пять рецептов; меню повторяет их, порции масштабируются по энергии, а не оптимизируются по каждому макронутриенту. Макроцели являются ориентирами, фактические значения зависят от ингредиентов. Телосложение влияет на стартовый объём тренировок, но не на формулу обмена. Планы не учитывают травмы, заболевания или беременность и рассчитаны на взрослых. Объёмные элементы созданы CSS, без WebGL. Пользовательские данные остаются в браузере, удаление данных браузера удаляет профиль.
