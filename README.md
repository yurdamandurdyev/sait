# FORMA

Русскоязычное приложение для калорий, питания и тренировок. Чёрно-красная и бело-оранжевая темы, настоящие WebGL-сцены с объёмными мешами, локальные иллюстрации и адаптивная вёрстка. Без внешних зависимостей и сетевых запросов.

## Открыть приложение

Скачайте **index.html** через Download raw file на GitHub и откройте двойным щелчком. Стили, код, рецепты, иллюстрации и 3D-движок встроены в этот файл. Интернет и сервер не нужны.

## Разработка

Требуется Node.js 20+. В существующей рабочей папке:

```sh
cd /workspace/sait
npm run build
npm test
npm start
```

Сервер слушает 0.0.0.0:3000. Порт можно изменить через PORT. После изменения исходников выполните `npm run build`: он обновит `bundle.js` и автономный `index.html`. Разметка редактируется в `index.template.html`.

## Питание

- 56 рецептов: 14 завтраков, 14 обедов, 14 ужинов и 14 перекусов.
- В стандартном недельном плане каждый приём пищи отличается во все семь дней, включая вегетарианский вариант с яйцами и молочными продуктами.
- Кнопка «Заменить» позволяет выбрать другое блюдо той же категории. «Новый вариант недели» меняет подборку. При ручной замене можно выбрать уже использованное блюдо.
- Порции всех блюд дня масштабируются по калориям. Замена пересчитывает порции и ингредиенты недельной корзины.
- Калории и БЖУ рецептов получены из приблизительного среднего состава ингредиентов, а не из лабораторного анализа или конкретных этикеток. Фактические БЖУ меню показаны отдельно от целевых.
- Каталог поддерживает поиск, фильтры и сортировку по времени или белку. В каталоге — базовые порции, в меню — персональные.
- Корзина содержит количество ингредиентов за семь дней; можно отмечать покупки и скачивать текстовый список. Вес круп — сухой, бобовых — готовый, яйца указаны по весу без скорлупы.

## 3D и оформление

`scene.js` — небольшой собственный WebGL-рендерер: торы, сферы, кубы и цилиндры, освещение, блики, вращение и параллакс. Сцены находятся на главной, в профиле, питании, рецептах, тренировках и корзине. Карточки и декоративные элементы используют дополнительные CSS-анимации. Переключатель тем и кнопка 3D-паузы находятся в шапке. Системная настройка уменьшения движения учитывается. За пределами экрана сцены не рендерятся; при паузе статический кадр сохраняется. Если WebGL недоступен, показывается CSS-композиция.

## Данные и ограничения

Данные сохраняются только в localStorage браузера: аккаунтов, синхронизации и серверной базы нет. Дневник еды относится к текущему дню недели. Обновление меню сбрасывает отметки еды и покупок, сохраняя воду и тренировку. Расчёт Миффлина — Сан Жеора предназначен для взрослых; формула не зависит от субъективного телосложения. Порции оптимизируются по общей энергии, а не по точному попаданию в каждый макронутриент. Планы не учитывают заболевания, травмы или беременность. Удаление данных браузера удаляет сохранённый профиль.
